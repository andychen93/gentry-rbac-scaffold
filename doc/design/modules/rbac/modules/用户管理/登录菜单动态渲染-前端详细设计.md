# 一、模块概述

## 1.1 功能描述

登录成功后，后端返回当前用户拥有的菜单树（通过角色关联菜单推导）。前端根据该菜单树：
1. **动态渲染侧边栏菜单** — 只显示用户有权限访问的菜单
2. **动态生成路由** — 只注册用户有权限的页面路由，无权限页面返回 404
3. **移除静态菜单和静态路由** — 删除 `FALLBACK_MENUS` 硬编码和 `App.tsx` 中写死的路由

## 1.2 问题背景

当前实现的问题：
- `AppSidebar.tsx` 中 `FALLBACK_MENUS` 硬编码了所有页面，与权限无关
- `App.tsx` 中静态注册了所有路由，用户无权限的页面也能访问
- 点击无权限菜单 → 后端返回 403 → 前端显示"网络异常"

## 1.3 模块边界

| 职责 | 说明 |
|------|------|
| **本设计负责** | 登录响应解析菜单树、动态菜单渲染、动态路由生成、菜单类型→组件映射 |
| **后端配合** | 登录接口返回用户拥有的菜单树（仅 type=1 目录 + type=2 菜单，不含 type=3 按钮） |
| **不变更** | 菜单管理 CRUD 页面（MenuPage）、角色分配菜单权限页面（PermissionPage） |

# 二、接口变更

## 2.1 后端接口变更

### AUTH-001 登录接口响应变更

登录接口响应的 `userInfo` 新增 `menus` 字段，返回当前用户拥有的菜单树：

```json
{
  "code": 0,
  "data": {
    "token": "xxx",
    "userInfo": {
      "userId": 123,
      "username": "chenli",
      "nickname": "陈立",
      "roles": [...],
      "permissions": [...],
      "menus": [
        {
          "id": 10,
          "parentId": 0,
          "name": "系统管理",
          "path": "/system",
          "component": null,
          "icon": "SettingOutlined",
          "type": 1,
          "sort": 1,
          "visible": 1,
          "children": [
            {
              "id": 20,
              "parentId": 10,
              "name": "用户管理",
              "path": "/system/users",
              "component": "system/users",
              "icon": "UserOutlined",
              "type": 2,
              "sort": 1,
              "visible": 1,
              "children": []
            }
          ]
        }
      ]
    }
  }
}
```

**菜单树构建规则（后端）**：
- 查询用户角色关联的所有菜单 ID（`sys_role_menu`）
- 筛选 `type IN (1, 2)`（目录 + 菜单页面），排除 `type=3`（按钮权限）
- 筛选 `status = 1`（启用）且 `visible = 1`（可见）
- 构建树结构（`parentId = 0` 为根节点）
- 按父节点自动补充：如果子菜单属于角色权限，但其父目录不在权限中，自动带上父目录（保证树结构完整）

### 新增字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| menus | MenuNavItem[] | 用户可访问的菜单树，仅包含 type=1(目录) 和 type=2(菜单) |
| menus[].component | string \| null | type=2 时为前端组件路径（如 `system/users`），type=1 时为 null |

## 2.2 MenuNavItem 类型定义

```typescript
interface MenuNavItem {
  id: number;
  parentId: number;
  name: string;
  path: string | null;       // type=1 目录可为 null 或父路径
  component: string | null;  // type=2 菜单的组件路径
  icon: string | null;
  type: 1 | 2;              // 1=目录 2=菜单
  sort: number;
  visible: 1 | 0;
  children: MenuNavItem[];
}
```

## 4.3 menuMapper 工具

新增 `utils/menuMapper.ts`，负责将后端菜单树转换为前端所需格式。

### 4.3.1 菜单树 → 侧边栏 MenuItem[]

```typescript
// 将 MenuNavItem[] 转换为侧边栏 MenuItem[]
export function toSidebarItems(menus: MenuNavItem[]): MenuItem[] {
  return menus
    .filter(m => m.visible === 1)
    .sort((a, b) => a.sort - b.sort)
    .map(m => {
      const item: MenuItem = {
        id: String(m.id),
        label: m.name,
        icon: m.icon || undefined,
        path: m.path || undefined,
      };
      if (m.children?.length) {
        item.children = toSidebarItems(m.children);
      }
      return item;
    });
}
```

### 4.3.2 菜单树 → 路由配置

```typescript
export interface RouteConfig {
  path: string;
  component: string;  // 组件路径，如 "system/users"
}

/** 从菜单树中提取所有 type=2 的叶子菜单，生成路由配置 */
export function toRouteConfigs(menus: MenuNavItem[]): RouteConfig[] {
  const routes: RouteConfig[] = [];
  const walk = (list: MenuNavItem[]) => {
    for (const m of list) {
      if (m.type === 2 && m.path && m.component) {
        routes.push({ path: m.path, component: m.component });
      }
      if (m.children?.length) {
        walk(m.children);
      }
    }
  };
  walk(menus);
  return routes;
}
```

## 4.4 组件路径 → 懒加载映射

```typescript
// components/common/LazyPage.tsx

import { lazy, Suspense } from 'react';
import { Spin } from 'antd';

/** 组件路径 → lazy() 映射表 */
const pageModules = import.meta.glob<{ default: React.ComponentType }>(
  '../../pages/**/*.tsx'
);

const componentMap: Record<string, React.LazyExoticComponent<any>> = {};

function getComponent(componentPath: string) {
  if (!componentMap[componentPath]) {
    const matchedKey = Object.keys(pageModules).find(
      key => key.includes(componentPath)
    );
    if (matchedKey) {
      componentMap[componentPath] = lazy(pageModules[matchedKey]);
    }
  }
  return componentMap[componentPath];
}

interface LazyPageProps {
  component: string;
}

export default function LazyPage({ component }: LazyPageProps) {
  const Comp = getComponent(component);
  if (!Comp) {
    return <div>页面组件未找到: {component}</div>;
  }
  return (
    <Suspense fallback={<Spin size="large" style={{ display: 'block', margin: '100px auto' }} />}>
      <Comp />
    </Suspense>
  );
}
```

## 4.5 App.tsx 动态路由

```typescript
// App.tsx
export default function App() {
  const isLoggedIn = useUserStore(s => s.isLoggedIn);
  const menus = useUserStore(s => s.menus);

  // 从菜单树生成路由配置
  const routes = useMemo(() => toRouteConfigs(menus), [menus]);

  return (
    <Routes>
      <Route path="/login" element={<LoginPage />} />
      <Route
        path="/*"
        element={
          <ProtectedRoute>
            <AppLayout>
              <Routes>
                {routes.map(r => (
                  <Route
                    key={r.path}
                    path={r.path.replace(/^\//, '')}
                    element={<LazyPage component={r.component} />}
                  />
                ))}
                {/* 角色权限分配页：无菜单入口，通过角色管理页跳转 */}
                <Route path="system/roles/:id/permissions" element={<PermissionPage />} />
                {/* 兜底：无匹配路由 → 跳转第一个有权限的页面 */}
                <Route path="*" element={<NavigateToFirstMenu menus={menus} />} />
              </Routes>
            </AppLayout>
          </ProtectedRoute>
        }
      />
    </Routes>
  );
}

/** 跳转到第一个有权限的页面 */
function NavigateToFirstMenu({ menus }: { menus: MenuNavItem[] }) {
  const firstPath = useMemo(() => {
    for (const m of menus) {
      if (m.path && m.type === 2) return m.path;
      if (m.children?.length) {
        for (const c of m.children) {
          if (c.path && c.type === 2) return c.path;
        }
      }
    }
    return '/system/users';
  }, [menus]);
  return <Navigate to={firstPath} replace />;
}
```

# 六、错误处理设计

| 场景 | 处理策略 |
|------|---------|
| 登录接口不返回 menus | menus 默认为空数组，侧边栏为空，跳转到 404 提示 |
| menus 为空 | 显示"请联系管理员分配权限"提示页 |
| component 映射不到文件 | 显示"页面组件未找到"提示 |
| 用户无任何菜单权限 | 跳转无权限提示页，提供退出登录按钮 |

# 七、测试设计

## 7.1 正常流程

| 场景 | 操作 | 预期 |
|------|------|------|
| 管理员登录 | ADMIN 角色登录 | 侧边栏显示所有菜单 |
| 普通用户登录 | 仅分配"用户管理"权限 | 侧边栏只显示"系统管理 > 用户管理" |
| 菜单排序 | 后端调整菜单 sort 值 | 前端菜单按 sort 排列 |
| 隐藏菜单 | visible=0 | 侧边栏不显示该菜单 |

## 7.2 异常流程

| 场景 | 操作 | 预期 |
|------|------|------|
| 无菜单权限 | 角色未分配任何菜单 | 显示无权限提示，可退出登录 |
| 直接访问无权限 URL | 浏览器输入 /system/tenants | 路由未注册，跳转第一个有权限页面 |
| component 不存在 | 数据库 component 值写错 | 显示"页面组件未找到" |
