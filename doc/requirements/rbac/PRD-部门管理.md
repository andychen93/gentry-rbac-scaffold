## 一、功能概述

### 1.1 功能定位

部门管理负责维护企业的组织架构，支持多级部门树结构。部门是数据权限控制的重要维度，用户可按部门进行数据隔离。

### 1.2 业务场景

| 场景 | 描述 | 操作角色 |
|------|------|---------|
| 组织架构搭建 | 创建企业的部门结构 | 管理员 |
| 部门调整 | 修改部门信息、调整层级 | 管理员 |
| 人员调动 | 将用户从一个部门调到另一个 | 管理员 |
| 数据权限控制 | 按部门范围控制数据访问 | 系统自动 |

### 1.3 用户故事

```
作为一名【系统管理员】
我想要【管理组织架构】
以便于【按部门划分用户和数据权限】

验收标准：
- 可创建多级部门树结构
- 可设置部门负责人
- 可调整部门排序和层级
- 可查看部门下的用户数量
```

### 2.3 新增部门（D-002）

#### 功能描述

创建新部门节点，支持选择父级部门。

#### 新增表单字段

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 | 说明 |
|------|---------|------|------|---------|------|
| parentId | 上级部门 | TreeSelect | 否 | - | 默认为顶级 |
| name | 部门名称 | Input | 是 | 2-50字符 | 租户内唯一 |
| leaderId | 负责人 | UserSelect | 否 | - | 用户选择器 |
| phone | 联系电话 | Input | 否 | 手机号格式 | - |
| email | 邮箱 | Input | 否 | 邮箱格式 | - |
| sort | 显示排序 | InputNumber | 是 | 0-999 | - |
| status | 部门状态 | Switch | 否 | 默认启用 | - |

#### 接口设计

```
POST /api/v1/depts
```

**请求参数：**

```json
{
  "parentId": 1,
  "name": "华东分公司",
  "leaderId": 10,
  "phone": "13800138001",
  "email": "huadong@example.com",
  "sort": 1,
  "status": 1
}
```

#### 业务规则

| 规则编号 | 规则描述 |
|---------|---------|
| BR-001 | 部门名称租户内唯一 |
| BR-002 | 部门层级最多5级（可配置） |
| BR-003 | 负责人必须是本租户用户 |

---

### 2.4 编辑部门（D-003）

#### 功能描述

修改部门基本信息。

#### 业务规则

| 规则编号 | 规则描述 |
|---------|---------|
| BR-001 | 不能将部门移动到自己的子部门下 |
| BR-002 | 上级部门不能是自己 |

#### 接口设计

```
PUT /api/v1/depts/{id}
```

---

### 2.5 删除部门（D-004）

#### 功能描述

删除部门节点，需确保部门下无用户且无子部门。

#### 业务规则

| 规则编号 | 规则描述 |
|---------|---------|
| BR-001 | 存在子部门时不允许删除 |
| BR-002 | 存在用户时不允许删除 |
| BR-003 | 删除操作需要二次确认 |

#### 接口设计

```
DELETE /api/v1/depts/{id}
```

**响应（删除失败）：**

```json
{
  "code": 40001,
  "message": "存在子部门，不允许删除",
  "data": null
}
```

## 三、数据模型

### 3.1 部门表（sys_dept）

| 字段名 | 类型 | 可空 | 默认值 | 说明 |
|--------|------|------|--------|------|
| id | BIGINT | NO | - | 主键（雪花算法） |
| tenant_id | BIGINT | NO | - | 租户ID |
| parent_id | BIGINT | NO | 0 | 父部门ID，顶级为0 |
| ancestors | VARCHAR(500) | NO | - | 祖级列表，如 0,1,2 |
| name | VARCHAR(50) | NO | - | 部门名称 |
| leader_id | BIGINT | YES | NULL | 负责人用户ID |
| phone | VARCHAR(20) | YES | NULL | 联系电话 |
| email | VARCHAR(100) | YES | NULL | 邮箱 |
| sort | INT | NO | 0 | 显示排序 |
| status | SMALLINT | NO | 1 | 状态：0=禁用，1=启用 |
| create_time | TIMESTAMP | NO | CURRENT_TIMESTAMP | 创建时间 |
| update_time | TIMESTAMP | NO | CURRENT_TIMESTAMP | 更新时间 |
| deleted | SMALLINT | NO | 0 | 逻辑删除 |

### 3.2 索引设计

| 索引名 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| pk_sys_dept | id | PRIMARY | 主键索引 |
| idx_tenant_parent | tenant_id, parent_id | NORMAL | 租户内父部门索引 |
| uk_tenant_name | tenant_id, name, deleted | UNIQUE | 租户内名称唯一 |
