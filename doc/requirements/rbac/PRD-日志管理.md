## 一、功能概述

### 1.1 功能定位

日志管理负责记录系统的操作日志和登录日志，提供审计追踪和安全监控能力。操作日志记录用户的关键业务操作，登录日志记录用户的登录行为。

### 1.2 业务场景

| 场景 | 描述 | 操作角色 |
|------|------|---------|
| 操作审计 | 查看用户操作记录 | 管理员 |
| 问题排查 | 通过日志定位问题原因 | 管理员/开发 |
| 登录监控 | 监控异常登录行为 | 管理员 |
| 安全分析 | 分析登录趋势和风险 | 管理员 |

### 1.3 用户故事

```
作为一名【系统管理员】
我想要【查看操作和登录日志】
以便于【审计追踪和安全监控】

验收标准：
- 可查看操作日志列表
- 可查看登录日志列表
- 支持多条件筛选
- 可查看日志详情
- 可清理历史日志
```

### 2.2 操作日志列表（OL-001）

#### 功能描述

#### 筛选条件

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|---------|------|
| 操作模块 | string | 否 | 模块名称模糊匹配 |
| 操作类型 | select | 否 | 新增/修改/删除/查询/导出/导入 |
| 操作人员 | string | 否 | 操作人用户名 |
| 操作状态 | select | 否 | 成功/失败 |
| 操作时间 | dateRange | 否 | 时间范围 |

#### 列表字段

| 字段 | 显示名称 | 宽度 | 是否排序 | 说明 |
|------|---------|------|---------|------|
| module | 操作模块 | 120px | 否 | 模块名称 |
| type | 操作类型 | 80px | 否 | Tag 展示 |
| title | 操作描述 | 200px | 否 | 操作说明 |
| operator | 操作人员 | 100px | 否 | 用户名 |
| operator_ip | 操作IP | 120px | 否 | - |
| location | 操作地点 | 100px | 否 | IP归属地 |
| status | 操作状态 | 80px | 否 | Tag 展示 |
| cost_time | 耗时(ms) | 80px | 是 | 执行时间 |
| operate_time | 操作时间 | 150px | 是 | - |

#### 操作类型样式

| 类型 | 标签颜色 | 说明 |
|------|---------|------|
| 新增 | green | 新增操作 |
| 修改 | blue | 修改操作 |

| 查询 | default | 查询操作 |
| 导出 | orange | 导出操作 |

**请求参数：**

## 四、日志记录规则

### 4.1 操作日志记录规则

通过注解方式声明需要记录的操作：

```java
@Log(module = "用户管理", type = LogType.INSERT, title = "新增用户")
@PostMapping
public Result<UserVO> create(@RequestBody UserCreateDTO dto) {
    // ...
}
```

#### 注解参数

| 参数 | 类型 | 说明 |
|------|------|------|
| module | String | 操作模块 |
| type | LogType | 操作类型（INSERT/UPDATE/DELETE/SELECT/EXPORT/IMPORT） |
| title | String | 操作描述，支持 SpEL 表达式 |
| isSaveRequest | boolean | 是否保存请求参数，默认 true |
| isSaveResponse | boolean | 是否保存响应结果，默认 true |
| condition | String | 记录条件，SpEL 表达式 |

#### 记录时机

| 场景 | 是否记录 | 说明 |
|------|---------|------|
| 新增操作 | 是 | 新增成功后记录 |
| 修改操作 | 是 | 修改成功后记录 |
| 删除操作 | 是 | 删除成功后记录 |
| 查询操作 | 可选 | 默认不记录 |
| 导出操作 | 是 | 导出时记录 |
| 导入操作 | 是 | 导入时记录 |
| 登录操作 | 否 | 登录日志单独记录 |

### 4.2 登录日志记录规则

#### 记录时机

| 场景 | 是否记录 | 状态 |
|------|---------|------|
| 登录成功 | 是 | 成功 |
| 登录失败 | 是 | 失败 |
| 退出登录 | 是 | 成功 |

#### 记录内容

| 字段 | 来源 |
|------|------|
| username | 用户输入 |
| login_type | 认证方式 |
| login_ip | HttpServletRequest.getRemoteAddr() |
| location | IP归属地解析（离线库/API） |
| browser | User-Agent 解析 |
| os | User-Agent 解析 |
| status | 登录结果 |
| message | 结果描述 |
