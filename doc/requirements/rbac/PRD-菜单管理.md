## 一、功能概述

### 1.1 功能定位

菜单管理负责维护系统的菜单结构和按钮权限，是权限控制的基础。通过菜单管理可以灵活配置系统的导航结构和操作权限。

### 1.2 菜单类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **目录** | 菜单容器，不对应实际页面 | 系统管理、监控中心 |
| **菜单** | 实际页面，对应前端路由 | 用户管理、角色管理 |
| **按钮** | 页面内的操作按钮权限 | 新增用户、删除用户 |

### 1.3 用户故事

```
作为一名【系统管理员】
我想要【管理菜单和按钮权限】
以便于【控制用户能看到哪些菜单和能执行哪些操作】

验收标准：
- 可创建目录、菜单、按钮三种类型
- 可设置菜单的路由、图标、排序
- 可设置按钮的权限标识
- 菜单以树形结构展示
```

### 2.3 新增菜单（M-002）

#### 功能描述

创建新的菜单项，支持三种类型：目录、菜单、按钮。

#### 新增表单字段

##### 公共字段（所有类型）

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 | 说明 |
|------|---------|------|------|---------|------|
| parentId | 上级菜单 | TreeSelect | 否 | - | 顶级菜单选择"主类目" |
| name | 菜单名称 | Input | 是 | 2-50字符 | - |
| type | 菜单类型 | Radio | 是 | - | 目录/菜单/按钮 |
| sort | 显示排序 | InputNumber | 是 | 0-999 | - |
| status | 菜单状态 | Switch | 否 | 默认启用 | - |

##### 目录类型专属字段

| 字段 | 显示名称 | 类型 | 必填 | 说明 |
|------|---------|------|------|------|
| icon | 菜单图标 | IconSelect | 否 | 图标选择器 |
| path | 路由地址 | Input | 否 | 如 /system |

##### 菜单类型专属字段

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 | 说明 |
|------|---------|------|------|---------|------|
| icon | 菜单图标 | IconSelect | 否 | - | 图标选择器 |
| path | 路由地址 | Input | 是 | 以/开头 | 如 /system/user |
| component | 组件路径 | Input | 是 | - | 如 system/user/index |
| permission | 权限标识 | Input | 否 | - | 如 system:user |
| visible | 显示状态 | Switch | 否 | 默认显示 | 是否在菜单中显示 |
| isExternal | 是否外链 | Switch | 否 | 默认否 | 外链在新窗口打开 |
| isCache | 是否缓存 | Switch | 否 | 默认否 | 是否缓存页面 |
| isActive | 路由参数 | Input | 否 | - | 如 id |
| query | 路由参数 | Input | 否 | - | 如 {"id": 1} |

##### 按钮类型专属字段

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 | 说明 |
|------|---------|------|------|---------|------|
| permission | 权限标识 | Input | 是 | 格式：module:entity:action | 如 system:user:add |

#### 接口设计

```
POST /api/v1/menus
```

**请求参数（菜单类型示例）：**

```json
{
  "parentId": 1,
  "name": "用户管理",
  "type": 2,
  "icon": "user",
  "path": "/system/user",
  "component": "system/user/index",
  "permission": "system:user",
  "sort": 1,
  "visible": 1,
  "status": 1,
  "isExternal": 0,
  "isCache": 0
}
```

### 2.4 编辑菜单（M-003）

#### 功能描述

修改菜单信息，根据菜单类型显示不同的表单字段。

#### 业务规则

| 规则编号 | 规则描述 |
|---------|---------|
| BR-001 | 不能将菜单移动到自己的子菜单下 |
| BR-002 | 菜单类型创建后不可修改 |
| BR-003 | 外链菜单的 path 必须是完整 URL |

#### 接口设计

```
PUT /api/v1/menus/{id}
```

---

### 2.5 删除菜单（M-004）

#### 功能描述

删除菜单项，同时删除其所有子菜单和关联的角色权限。

#### 业务规则

| 规则编号 | 规则描述 |
|---------|---------|
| BR-001 | 删除菜单时级联删除所有子菜单 |
| BR-002 | 删除菜单时同时删除角色菜单关联记录 |
| BR-003 | 删除操作需要二次确认 |

#### 接口设计

```
DELETE /api/v1/menus/{id}
```

## 三、数据模型

### 3.1 菜单表（sys_menu）

| 字段名 | 类型 | 可空 | 默认值 | 说明 |
|--------|------|------|--------|------|
| id | BIGINT | NO | - | 主键 |
| parent_id | BIGINT | NO | 0 | 父菜单ID，顶级为0 |
| name | VARCHAR(50) | NO | - | 菜单名称 |
| icon | VARCHAR(100) | YES | NULL | 菜单图标 |
| type | SMALLINT | NO | - | 类型：1=目录，2=菜单，3=按钮 |
| sort | INT | NO | 0 | 显示排序 |
| permission | VARCHAR(100) | YES | NULL | 权限标识 |
| path | VARCHAR(200) | YES | NULL | 路由地址 |
| component | VARCHAR(200) | YES | NULL | 组件路径 |
| visible | SMALLINT | NO | 1 | 是否显示：0=隐藏，1=显示 |
| status | SMALLINT | NO | 1 | 状态：0=禁用，1=启用 |
| is_external | SMALLINT | NO | 0 | 是否外链 |
| is_cache | SMALLINT | NO | 0 | 是否缓存 |
| active | VARCHAR(200) | YES | NULL | 路由参数 |
| query | VARCHAR(200) | YES | NULL | 路由参数JSON |
| create_time | TIMESTAMP | NO | CURRENT_TIMESTAMP | 创建时间 |
| update_time | TIMESTAMP | NO | CURRENT_TIMESTAMP | 更新时间 |
| deleted | SMALLINT | NO | 0 | 逻辑删除 |

### 3.2 索引设计

| 索引名 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| pk_sys_menu | id | PRIMARY | 主键索引 |
| idx_parent_id | parent_id | NORMAL | 父菜单索引 |
| idx_permission | permission | NORMAL | 权限标识索引 |
