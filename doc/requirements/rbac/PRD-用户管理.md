## 一、功能概述

### 1.1 功能定位

用户管理负责维护平台用户账号，实现用户的全生命周期管理，包括创建、编辑、禁用、删除、密码重置、角色分配等。

### 1.2 业务场景

| 场景 | 描述 | 操作角色 |
|------|------|---------|
| 新员工入职 | 创建用户账号，分配部门和角色 | 管理员 |
| 员工离职 | 禁用或删除用户账号 | 管理员 |
| 密码重置 | 用户忘记密码时管理员重置 | 管理员 |
| 角色变更 | 调整用户的角色权限 | 管理员 |
| 用户自查 | 用户查看和修改自己的信息 | 用户本人 |

### 1.3 用户故事

```
作为一名【系统管理员】
我想要【管理用户账号】
以便于【控制谁能访问系统以及能做什么操作】

验收标准：
- 可创建用户并分配部门和角色
- 可修改用户信息
- 可重置用户密码
- 可禁用/启用用户
- 可给用户分配多个角色
```

```
├────────────────┬─────────────────────────────────────────────────────┤
│  组织架构       │  🔍 用户名 [____] 手机号 [____] 状态 [全部 ▼] [搜索] │
│  ├─ 总公司 (25) │                                                     │
│  │  ├─ 运营部(8)│  [+ 新增用户]  [导入]  [导出]      [刷新]            │
│  │  ├─ 技术部(10)│                                                    │
│  │  └─ 财务部(7)│  ┌───────────────────────────────────────────────┐  │
│  └─ 分公司 (15) │  │用户名│昵称│部门│手机│状态│创建时间│操作      │  │
│     ├─ 华东(5)  │  ├───────────────────────────────────────────────┤  │
│     └─ 华南(10) │  │admin│管理员│运营部│138..│启用│2026-01│...    │  │
│                │  │zhangsan│张三│技术部│139..│启用│2026-02│...    │  │
│                │  └───────────────────────────────────────────────┘  │
│                │  共 25 条  < 1 2 3 >                                  │
└────────────────┴─────────────────────────────────────────────────────┘
```

#### 筛选条件

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|---------|------|
| 部门 | tree | 否 | 左侧部门树选择 |
| 用户名 | string | 否 | 模糊匹配 |
| 手机号 | string | 否 | 精确匹配 |
| 状态 | int | 否 | 0=禁用，1=启用，空=全部 |

#### 列表字段

| 字段 | 显示名称 | 宽度 | 是否排序 | 说明 |
|------|---------|------|---------|------|
| username | 用户名 | 120px | 是 | 登录用户名 |
| nickname | 昵称 | 100px | 否 | 显示名称 |
| dept_name | 部门 | 150px | 否 | 所属部门名称 |
| phone | 手机号 | 120px | 否 | - |
| email | 邮箱 | 180px | 否 | - |
| status | 状态 | 80px | 否 | Tag 展示 |
| create_time | 创建时间 | 150px | 是 | - |
| operation | 操作 | 200px | - | 操作按钮 |

#### 操作按钮

| 按钮 | 显示条件 | 点击行为 |
|------|---------|---------|
| 详情 | 始终显示 | 弹出详情抽屉 |
| 编辑 | 始终显示 | 弹出编辑表单 |
| 删除 | 非当前用户 | 确认后删除 |
| 重置密码 | 始终显示 | 弹出重置密码确认 |
| 分配角色 | 始终显示 | 弹出角色分配 |

#### 接口设计

```

```

**请求参数：**

| pageSize | int | 是 | 每页条数 |
| deptId | long | 否 | 部门ID（含子部门） |
| username | string | 否 | 用户名（模糊） |
| phone | string | 否 | 手机号 |
| status | int | 否 | 状态 |

**响应示例：**

### 2.3 新增用户（U-002）

#### 功能描述

创建新用户账号，设置基本信息并分配角色。

#### 新增表单字段

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 | 说明 |
|------|---------|------|------|---------|------|
| username | 用户名 | Input | 是 | 4-20字符，字母开头，字母数字下划线 | 登录账号 |
| nickname | 昵称 | Input | 是 | 2-20字符 | 显示名称 |
| deptId | 所属部门 | TreeSelect | 是 | - | 部门树选择 |
| phone | 手机号 | Input | 是 | 11位手机号 | - |
| email | 邮箱 | Input | 否 | 邮箱格式 | - |
| gender | 性别 | Radio | 否 | - | 男/女/未知 |
| postName | 职务 | DictSelect | 否 | - | 从字典 sys_user_post 选择 |
| password | 密码 | InputPassword | 是 | 8-20位，含大小写字母+数字 | 初始密码 |
| confirmPassword | 确认密码 | InputPassword | 是 | 与password一致 | - |
| status | 状态 | Switch | 否 | 默认启用 | - |
| roleIds | 角色 | Transfer | 否 | - | 穿梭框选择 |
| remark | 备注 | TextArea | 否 | 最多200字符 | - |

#### 接口设计

```
POST /api/v1/users
```

**请求参数：**

```json
{
  "username": "zhangsan",
  "nickname": "张三",
  "deptId": 2,
  "phone": "13800138001",
  "email": "zhangsan@example.com",
  "gender": 1,
  "password": "Abc@123456",
  "status": 1,
  "roleIds": [2, 3],
  "remark": "运营部员工"
}
```

#### 业务规则

| 规则编号 | 规则描述 |
|---------|---------|
| BR-001 | 用户名租户内唯一 |
| BR-002 | 手机号租户内唯一 |
| BR-003 | 密码必须加密存储（BCrypt） |
| BR-004 | 可分配多个角色，权限取并集 |
| BR-005 | 部门必须选择叶子节点或允许选择任意层级 |

### 2.5 删除用户（U-005）

#### 功能描述

逻辑删除用户，删除后用户无法登录。

#### 业务规则

| 规则编号 | 规则描述 |
|---------|---------|
| BR-001 | 不能删除当前登录用户 |
| BR-002 | 不能删除租户管理员（admin） |
| BR-003 | 删除为逻辑删除，数据保留 |
| BR-004 | 删除操作需二次确认 |

#### 接口设计

```
DELETE /api/v1/users/{id}
```
