## 一、功能概述

### 1.1 功能定位

字典管理用于维护系统中的枚举数据和配置项，提供统一的字典数据管理能力，支持多租户隔离。字典分为字典类型和字典数据两级结构。

### 1.2 业务场景

| 场景 | 描述 | 操作角色 |
|------|------|---------|
| 字典类型维护 | 创建和管理字典分类 | 管理员 |
| 字典数据维护 | 维护字典下的具体数据项 | 管理员 |
| 前端下拉框 | 获取字典数据填充下拉框 | 系统 |
| 业务字典查询 | 根据字典类型获取数据列表 | 系统/业务 |

### 1.3 用户故事

```
作为一名【系统管理员】
我想要【管理字典数据】
以便于【统一维护系统中的枚举值和配置项】

验收标准：
- 可创建字典类型
- 可维护字典数据项
- 支持字典数据排序
- 支持字典缓存刷新
```

### 2.2 字典类型列表（D-001）

#### 功能描述

以分页列表形式展示所有字典类型，支持筛选。

#### 筛选条件

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|---------|------|
| 字典名称 | string | 否 | 模糊匹配 |
| 字典类型 | string | 否 | 精确匹配 |
| 状态 | int | 否 | 0=禁用，1=启用，空=全部 |

#### 列表字段

| 字段 | 显示名称 | 宽度 | 是否排序 | 说明 |
|------|---------|------|---------|------|
| dict_name | 字典名称 | 150px | 是 | 显示名称 |
| dict_type | 字典类型 | 150px | 否 | 唯一标识 |
| data_count | 数据项数 | 100px | 否 | 关联数据量 |
| status | 状态 | 80px | 否 | Tag 展示 |
| remark | 备注 | 200px | 否 | - |
| create_time | 创建时间 | 150px | 是 | - |
| operation | 操作 | 200px | - | 操作按钮 |

#### 操作按钮

| 按钮 | 显示条件 | 点击行为 |
|------|---------|---------|
| 数据 | 始终显示 | 跳转到字典数据管理 |
| 编辑 | 始终显示 | 弹出编辑表单 |
| 删除 | 数据项数为0 | 确认后删除 |

#### 接口设计

```
GET /api/v1/dict/types
```

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "list": [
      {
        "id": 1,
        "dictName": "用户性别",
        "dictType": "sys_user_gender",
        "dataCount": 3,
        "status": 1,
        "remark": "用户性别字典",
        "createTime": "2026-01-15T10:30:00"
      }
    ],
    "total": 10
  }
}
```

### 2.3 新增字典类型（D-002）

#### 功能描述

创建新的字典类型分类。

#### 新增表单字段

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 | 说明 |
|------|---------|------|------|---------|------|
| dictName | 字典名称 | Input | 是 | 2-50字符 | 显示名称 |
| dictType | 字典类型 | Input | 是 | 2-100字符，字母开头，字母数字下划线 | 租户内唯一 |
| status | 状态 | Switch | 否 | 默认启用 | - |
| remark | 备注 | TextArea | 否 | 最多200字符 | - |

#### 接口设计

```
POST /api/v1/dict/types
```

**请求参数：**

```json
{
  "dictName": "车辆状态",
  "dictType": "biz_vehicle_status",
  "status": 1,
  "remark": "车辆运行状态"
}
```

#### 业务规则

| 规则编号 | 规则描述 |
|---------|---------|
| BR-001 | 字典类型租户内唯一 |
| BR-002 | 字典类型建议以模块前缀开头，如 sys_、biz_ |

### 2.4 编辑字典类型（D-003）

#### 功能描述

修改字典类型基本信息，字典类型编码不可修改。

#### 可编辑字段

| 字段 | 是否可编辑 | 说明 |
|------|-----------|------|
| 字典类型编码 | ❌ 不可编辑 | 唯一标识，创建后不可变 |
| 字典名称 | ✅ 可编辑 | - |
| 状态 | ✅ 可编辑 | - |
| 备注 | ✅ 可编辑 | - |

#### 接口设计

```
PUT /api/v1/dict/types/{id}
```

---

### 2.5 删除字典类型（D-004）

#### 功能描述

逻辑删除字典类型及其下所有字典数据。

#### 业务规则

| 规则编号 | 规则描述 |

| BR-001 | 删除字典类型时级联删除所有字典数据 |

DELETE /api/v1/dict/types/{id}

#### 列表字段

| 字段 | 显示名称 | 宽度 | 说明 |
|------|---------|------|------|
| dict_label | 字典标签 | 150px | 显示文本 |
| dict_value | 字典键值 | 100px | 存储值 |
| sort | 排序 | 80px | 显示顺序 |
| css_class | 样式属性 | 100px | Tag 样式 |
| list_class | 列表样式 | 100px | 表格行样式 |
| status | 状态 | 80px | Tag 展示 |
| remark | 备注 | 150px | - |
| operation | 操作 | 150px | 操作按钮 |

#### 新增/编辑表单字段

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 | 说明 |
|------|---------|------|------|---------|------|
| dictLabel | 字典标签 | Input | 是 | 2-50字符 | 显示文本 |
| dictValue | 字典键值 | Input | 是 | 1-100字符 | 存储值 |
| sort | 排序 | InputNumber | 否 | 0-999 | 显示顺序 |
| cssClass | 样式属性 | Select | 否 | - | Tag 样式 |
| listClass | 表格样式 | Select | 否 | - | 表格行样式 |
| isDefault | 是否默认 | Switch | 否 | 默认否 | 是否默认选中 |
| status | 状态 | Switch | 否 | 默认启用 | - |
| remark | 备注 | TextArea | 否 | 最多200字符 | - |

#### 样式属性选项

| 值 | 说明 | 预览效果 |
|----|------|---------|
| primary | 主要（蓝色） | Tag 蓝色 |
| success | 成功（绿色） | Tag 绿色 |
| warning | 警告（橙色） | Tag 橙色 |
| danger | 危险（红色） | Tag 红色 |
| default | 默认（灰色） | Tag 灰色 |

## 四、前端集成

### 4.1 字典选择器组件

封装统一的字典选择组件，供各业务模块使用：

```typescript
// 字典选择器 Props
interface DictSelectProps {
  dictType: string;        // 字典类型
  value?: string;          // 当前值
  onChange?: (value: string) => void;
  placeholder?: string;
  disabled?: boolean;
  allowClear?: boolean;
}

// 使用示例
<DictSelect
  dictType="sys_user_gender"
  value={gender}
  onChange={setGender}
  placeholder="请选择性别"
/>
```

### 4.2 字典标签组件

用于在表格中展示字典值对应的标签：

```typescript
// 字典标签 Props
interface DictTagProps {
  dictType: string;        // 字典类型
  value: string | number;  // 字典值
}

// 使用示例
<DictTag dictType="sys_user_gender" value={user.gender} />
// 渲染结果: <Tag color="primary">男</Tag>
```
