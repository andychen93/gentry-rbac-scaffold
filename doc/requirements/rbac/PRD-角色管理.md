## 一、功能概述

### 1.1 功能定位

角色管理是 RBAC 权限模型的核心，通过角色将权限打包，再分配给用户，实现权限的灵活管理和复用。

### 1.2 业务场景

| 场景 | 描述 | 操作角色 |
|------|------|---------|
| 新建角色 | 创建新的业务角色 | 管理员 |
| 权限分配 | 给角色分配菜单和按钮权限 | 管理员 |
| 数据权限 | 设置角色的数据访问范围 | 管理员 |
| 角色复用 | 将角色分配给多个用户 | 管理员 |

### 1.3 用户故事

```
作为一名【系统管理员】
我想要【管理角色和权限】
以便于【通过角色批量控制用户的访问权限】

验收标准：
- 可创建角色并设置数据权限范围
- 可给角色分配菜单和按钮权限
- 可查看角色下的用户列表
- 可禁用/启用角色
```

### 2.2 角色列表查询（R-001）

#### 功能描述

以分页列表形式展示所有角色，支持筛选和排序。

#### 筛选条件

| 字段 | 类型 | 是否必填 | 说明 |
|------|------|---------|------|
| 角色名称 | string | 否 | 模糊匹配 |
| 角色编码 | string | 否 | 精确匹配 |
| 状态 | int | 否 | 0=禁用，1=启用，空=全部 |

#### 列表字段

| 字段 | 显示名称 | 宽度 | 是否排序 | 说明 |
|------|---------|------|---------|------|
| role_code | 角色编码 | 120px | 否 | 唯一标识 |
| role_name | 角色名称 | 150px | 是 | 显示名称 |
| data_scope | 数据权限 | 150px | 否 | 数据范围名称 |
| user_count | 用户数量 | 100px | 否 | 关联用户数 |
| sort | 排序 | 80px | 是 | - |
| status | 状态 | 80px | 否 | Tag 展示 |
| create_time | 创建时间 | 150px | 是 | - |
| operation | 操作 | 250px | - | 操作按钮 |

#### 操作按钮

| 按钮 | 显示条件 | 点击行为 |
|------|---------|---------|
| 编辑 | 始终显示 | 弹出编辑表单 |
| 权限 | 始终显示 | 弹出菜单权限分配 |
| 数据权限 | 始终显示 | 弹出数据权限设置 |
| 用户 | 始终显示 | 弹出关联用户列表 |
| 删除 | 关联用户数为0 | 确认后删除 |
| 禁用/启用 | 始终显示 | 切换状态确认 |

#### 接口设计

```
GET /api/v1/roles
```

**响应示例：**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "list": [
      {
        "id": 1,
        "roleCode": "ADMIN",
        "roleName": "管理员",
        "dataScope": 1,
        "dataScopeName": "全部数据",
        "userCount": 3,
        "sort": 1,
        "status": 1,
        "createTime": "2026-01-15T10:30:00"
      }
    ],
    "total": 10
  }
}
```

### 2.3 新增角色（R-002）

#### 功能描述

创建新角色，设置基本信息和数据权限范围。

#### 新增表单字段

| 字段 | 显示名称 | 类型 | 必填 | 校验规则 | 说明 |
|------|---------|------|------|---------|------|
| roleCode | 角色编码 | Input | 是 | 2-20字符，字母开头 | 唯一标识 |
| roleName | 角色名称 | Input | 是 | 2-20字符 | 显示名称 |
| dataScope | 数据权限范围 | Select | 是 | - | 数据访问范围 |
| sort | 排序 | InputNumber | 否 | 0-999 | 显示顺序 |
| status | 状态 | Switch | 否 | 默认启用 | - |
| remark | 备注 | TextArea | 否 | 最多200字符 | - |

#### 数据权限范围选项

| 值 | 名称 | 说明 |
|----|------|------|
| 1 | 全部数据 | 可查看所有数据 |
| 2 | 本部门及子部门数据 | 可查看所属部门及下级部门数据 |
| 3 | 本部门数据 | 仅可查看所属部门数据 |
| 4 | 仅本人数据 | 仅可查看自己创建/负责的数据 |
| 5 | 自定义 | 指定可访问的部门列表 |

#### 接口设计

```
POST /api/v1/roles
```

**请求参数：**

```json
{
  "roleCode": "OPERATOR",
  "roleName": "运营人员",
  "dataScope": 3,
  "sort": 2,
  "status": 1,
  "remark": "负责日常运营工作"
}
```

### 2.5 删除角色（R-004）

#### 功能描述

逻辑删除角色，需确保无关联用户。

#### 业务规则

| 规则编号 | 规则描述 |
|---------|---------|
| BR-001 | 存在关联用户时禁止删除 |
| BR-002 | 系统内置角色（ADMIN、USER）不可删除 |
| BR-003 | 删除操作需二次确认 |

#### 接口设计

```
DELETE /api/v1/roles/{id}
```

## 三、数据模型

### 3.1 角色表（sys_role）

| 字段名 | 类型 | 可空 | 默认值 | 说明 |
|--------|------|------|--------|------|
| id | BIGINT | NO | - | 主键（雪花算法） |
| tenant_id | BIGINT | NO | - | 租户ID |
| role_code | VARCHAR(50) | NO | - | 角色编码 |
| role_name | VARCHAR(50) | NO | - | 角色名称 |
| data_scope | SMALLINT | NO | 1 | 数据权限范围 |
| sort | INT | NO | 0 | 排序 |
| status | SMALLINT | NO | 1 | 状态：0=禁用，1=启用 |
| remark | VARCHAR(500) | YES | NULL | 备注 |
| create_time | TIMESTAMP | NO | CURRENT_TIMESTAMP | 创建时间 |
| update_time | TIMESTAMP | NO | CURRENT_TIMESTAMP | 更新时间 |
| deleted | SMALLINT | NO | 0 | 逻辑删除 |

### 3.2 角色菜单关联表（sys_role_menu）

| 字段名 | 类型 | 可空 | 说明 |
|--------|------|------|------|
| id | BIGINT | NO | 主键 |
| role_id | BIGINT | NO | 角色ID |
| menu_id | BIGINT | NO | 菜单ID |

### 3.3 角色部门关联表（sys_role_dept）

| 字段名 | 类型 | 可空 | 说明 |
|--------|------|------|------|
| id | BIGINT | NO | 主键 |
| role_id | BIGINT | NO | 角色ID |
| dept_id | BIGINT | NO | 部门ID |

> 用于数据权限范围为"自定义"时存储可选部门

### 3.4 索引设计

**sys_role 表：**

| 索引名 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| pk_sys_role | id | PRIMARY | 主键索引 |
| uk_tenant_code | tenant_id, role_code | UNIQUE | 租户内角色编码唯一 |

## 四、预置角色

### 4.1 系统预置角色

| 角色编码 | 角色名称 | 数据权限 | 说明 |
|---------|---------|---------|------|
| ADMIN | 管理员 | 全部数据 | 租户管理员，拥有所有权限 |
| USER | 普通用户 | 仅本人数据 | 基础用户角色 |

### 4.2 建议扩展角色

| 角色编码 | 角色名称 | 数据权限 | 说明 |
|---------|---------|---------|------|
| OPERATOR | 运营人员 | 本部门数据 | 日常运营管理 |
| VIEWER | 观察员 | 本部门及子部门 | 只读权限 |
| DRIVER | 司机 | 仅本人数据 | 司机专用角色 |
